# Logistic Regression Classifier

This project demonstrates binary classification using Logistic Regression on a breast cancer dataset (Malignant vs Benign) using Scikit-learn, Pandas, and Matplotlib.

## 🔍 Objective
Build a binary classifier using logistic regression, evaluate its performance using various metrics, and visualize the results.

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📁 Dataset
The dataset used is `data.csv`, which includes features like `radius_mean`, `texture_mean`, etc., with the target column `diagnosis` (B for Benign, M for Malignant).

## 🚀 What You'll Learn
- Logistic Regression (binary classification)
- Data preprocessing
- Feature scaling
- Model evaluation: Confusion Matrix, ROC-AUC, Classification Report
- Visualization using Matplotlib and Seaborn
